# Insha's Love Gift 💗🐧

A cute, animated love-quest website for Insha Parvin, made with plain HTML, CSS, and JavaScript. It includes a red rose bouquet animation on the final page and works on GitHub Pages without Python or Render.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `insha-love-gift`.
2. Upload **`index.html`** and this `README.md` to the repository's root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **`main`** and folder **`/(root)`**, then save.
6. Wait a little, then open the Pages URL shown there. It will look like `https://YOUR-USERNAME.github.io/insha-love-gift/`.

The site is static, so it does not need Flask, Python hosting, or Render.
